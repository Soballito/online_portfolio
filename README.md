# Nico Soballa – Portfolio

Personal portfolio website of Nico Soballa: mechanical engineer, project manager and product designer from Dortmund.

- The website is in [`site/`](site/): a static single-page site (`index.html` + `images/`), no build step.
- Preview locally: `python3 -m http.server -d site` and open http://localhost:8000
- Live at https://soballito.github.io/online_portfolio/ — every push to `main` that changes `site/` redeploys it via [`.github/workflows/pages.yml`](.github/workflows/pages.yml).
- Background and editing notes: see [`HANDOFF.md`](HANDOFF.md).
